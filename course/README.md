Здесь на **каждый из 200 дней** лежит файл-заготовка: шапка с заданием
дня, связью с настоящим кодом игры и местом `TODO`, куда ты дописываешь
свой код. Идёшь по порядку — к концу собираешь и понимаешь **настоящую
игру BlockDuel** (не с нуля, а меняя реальный проект).

**Как работать с детьми:** только по порядку. Сегодня — один день.
Картинку смотрим в книге `book/maryam_v_mire_koda.html` (якорь `#d001`,
`#d002`…), задание делаем вместе, книгу закрываем. Вперёд не листаем.

Неделя 1 уже собрана целиком (семь вечеров, с картинками). Со дня 8
файлы пока заготовки — их дописываем, когда дойдём.
