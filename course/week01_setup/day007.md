### 🎯 Мини-проект недели — вместе с папой

1. На экране игры найдите большое слово **BlockDuel**.
2. Папа откроет файл `lib/ui/widgets/logo.dart`.
3. Ребёнок меняет слова `Block` и `Duel` на своё приветствие, например:

```
Привет, я Марьям!
```

4. Снова запустите:

```bash
flutter run -d chrome
```

И смотрите: игра поздоровалась вашими словами.
