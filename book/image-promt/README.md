# 🎨 image-promt — описания иллюстраций (на каждый день)

Здесь на **каждый из 200 дней** курса лежит файл с готовым описанием
иллюстрации (промптом) для книги «Марьям в Мире Кода». По ним ты
создаёшь картинки в любой нейросети для рисования.

## Как пользоваться

1. Открой файл нужного дня (например `day015.txt`).
2. Скопируй блок **«ГОТОВЫЙ ПРОМПТ»** и вставь в генератор изображений.
3. Не нравится результат — добавь деталь и сгенерируй снова (как отладка).

Стиль у всех промптов **единый** — чтобы картинки были «одной семьёй».
Промпты на английском (нейросети его понимают лучше), с русской подписью.

## Что внутри

- `00_cover.txt` — обложка книги.
- `01_maryam.txt` … `05_cats.txt` — портреты героев (мастер-промпты).
- `day001.txt` … `day200.txt` — иллюстрация на каждый день (по неделям/темам).

Лежит рядом с самой книгой: `../maryam_v_mire_koda.html` (в её главах указан
диапазон дней-иллюстраций). Курс с заготовками кода — `../../course/`.

Файлы сгенерированы `tools/gen_image_prompts.py` (регенерация — тем же скриптом).
