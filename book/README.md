# 📖 Книга «Марьям в Мире Кода»

Иллюстрированный учебник-курс (детская код-РПГ), из которого ребёнок от нуля
доходит до кросс-платформенного разработчика — строя **настоящую** игру BlockDuel.
200 дней по 3 часа, 29 недель, на каждый вечер — своя страница с сюжетом и заданием.

## Как открыть

- **Онлайн (GitHub Pages):** <https://alshfu.github.io/block-puzzle-pvp/book/> —
  отдельное web-приложение (`web/`), ставится на телефон, работает офлайн.
- **Файл:** `maryam_v_mire_koda.html` — исходник книги (нужна папка `images/` рядом).
  `maryam_v_mire_koda_online.html` — самодостаточный монолит с картинками внутри
  (для артефакта / отправки одним файлом).
- Открывается **как настоящая книга**: сначала заставка (детская комната зимним
  вечером, камин, котик, книга на полке — клик, и она раскрывается), потом
  разворот из двух страниц с переплётом и фолио. Листать: ← →, свайп, тап по краям.
  Кнопка «📜 Обычный вид» — обычная прокрутка. 🖨 — печать на A4 (глава/день с новой страницы).

## Что внутри

- **200 страниц-дней** (все 29 недель) — на каждый день три абзаца сюжета
  (сцена с героями → зверёнок объясняет идею → связь с настоящим кодом игры)
  и задание «вместе с папой»; в конце недели — мини-проект. Правило книги:
  на страницу ≥3 предложений, сюжет развёрнутый, без пустых мест.
- **15 концепт-глав + бонус** (00–14): те же идеи глубже, с настоящим кодом из
  `lib/core`, `lib/ui`, `server/`; тесты, отладка, «Крепость-сервер», Git, четыре платформы.
- **Практический трек** — честный путь: не «перепечатай игру», а скачай реальный
  проект, запусти и меняй по кусочку (заготовки — в `../course/`).
- **Карта курса на 200 дней** и **промпты для иллюстраций**.

## Как устроено (для правок)

| Что | Где | Пересборка |
|---|---|---|
| Исходник книги (CSS/JS/разметка, недели 1–2 руками) | `maryam_v_mire_koda.html` | — |
| Сюжет недель 3–6 | `../tools/gen_book_days.py` (`WEEKS` + `STORY`) | `python3 tools/gen_book_days.py` |
| Сюжет недель 7–29 | `../tools/book_days/weekNN.py` — по файлу на неделю (словарь `WEEK`) | то же |
| Онлайн-монолит с картинками | `maryam_v_mire_koda_online.html` | `python3 tools/gen_book_online.py` |
| Web-приложение (PWA) | `web/` — index/css/js/assets/manifest/sw | `python3 tools/gen_book_app.py` |
| Промпты иллюстраций | `image-promt/` | `python3 tools/gen_image_prompts.py` |

Правило: правим исходник или сюжет → пересобираем дни → онлайн → web → push в `main`
(Action сам выложит `web/` в `/book`).

## Иллюстрации

- `images/` — обложка, портреты героев, обложки всех 29 недель и сцены дней **1–42**.
- Дни **43–200** ещё рисуются по промптам из `image-promt/dayNNN.md`. Пока картинки нет,
  страница-день выходит со значком героя недели; положите `images/dayNNN.jpg` —
  и после пересборки сцена появится сама.

## Связанное

- `../course/` — заготовка-файл кода на **каждый из 200 дней** (шапка + `TODO`).
- `../RELEASE_CHECKLIST.md`, `../GO_LIVE_GUIDE.md` — как выложить игру в сторы.
- `../DEPLOY.md` — как книга деплоится вместе с прод-игрой.
