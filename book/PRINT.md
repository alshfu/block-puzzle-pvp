# Печать «Марьям в Мире Кода» — для типографии

## Что отдаём

1. **PDF:** `book/maryam_v_mire_koda_print.pdf` — макет страниц.
2. **Исходник HTML:** `book/print.html` (если типография просит правки).
3. **Обложка отдельно:** `book/images/00_cover.jpg` (квадрат, место под название сверху).

## Параметры заказа

| | |
|---|---|
| Формат | **210 × 210 мм** (квадрат, детская книга) |
| Ориентация | квадрат, спуск одинаковый |
| Полосы | см. число страниц в PDF (чётность: при КБС лучше кратно 4) |
| Цвет | **4+4** (полноцвет, обе стороны) |
| Бумага блока | мелованная матовая **130–150 г/м²** |
| Бумага обложки | мелованная **250–300 г/м²**, матовая ламинация |
| Переплёт | **КБС** (клеевой) при >48 полос; на скобу — если урежете до 40–48 |
| Вылеты | в этом PDF **нет** (поля внутри страницы 10–16 мм). Если нужен вылет 3–5 мм — скажите, добавим. |
| Цветовой профиль | RGB в файле; **CMYK конвертирует типография** (Coated FOGRA39 или их стандарт) |

## Как пересобрать PDF (дома)

Из корня репозитория:

```bash
python3 tools/gen_print_book.py

"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="$PWD/book/maryam_v_mire_koda_print.pdf" \
  "file://$PWD/book/print.html"
```

Проверьте в Preview: страницы квадратные, картинки не обрезаны, текст не вылезает.

## Что внутри по полосам (логика)

- 1 — обложка-иллюстрация
- 2 — титул
- 3 — герои
- далее неделя 1 (7 вечеров, картинка + текст)
- неделя 2 (7 вечеров, картинка + текст)
- недели 3–29 — по развороту: картинка темы / страница задания

Картинки информативные: по кадру видно тему недели (не «просто красиво»).

## Замечания для печатника

- Шрифты в макете системные (Georgia + Trebuchet), в PDF должны быть **embedded**.
- Растр иллюстраций ~1k px на сторону (~120 dpi на 190 мм). Для детской векторно-мультяшной графики допустимо; при желании можно допечатать с увеличением Lanczos, не «вытягивать резкость».
- Чёрный текст не составной: `#302A22` (почти чёрный). Можно заменить на 100K при спуске, если просите «экономичный чёрный».
