# BlockDuel 9×9 — v2.0.0 (macOS)

Соревновательный блок-пазл: два игрока по очереди ставят тетромино на общую
доску 9×9. Заполненная строка / столбец / бокс 3×3 очищается, очки достаются
игроку, чей ход вызвал очистку. Версия `2.0.0+1` — полный порт на **Dart +
Flutter (+ Flame + Riverpod)** (миграция с TypeScript/React).

## Что внутри

- **Офлайн-режимы** — vs Bot (3 уровня сложности), Hot-seat (два игрока на одном
  Mac), Arcade (соло на рекорд), Tutorial.
- **Онлайн PvP** — лобби, матчмейкинг, живой server-authoritative матч с
  reconnect и ремачем, глобальный ELO-лидерборд (K=24).
- **Прогрессия** — XP/уровни, ~120 ачивок, daily quests, магазин (две валюты,
  скины доски, power-ups), 12 аватаров.
- **3 темы** (neutral / candy / night), синтезированный звук и фоновая музыка.

## Установка

1. Скачайте `BlockDuel-macos-v2.0.0.zip` и распакуйте.
2. Перенесите `BlockDuel.app` в `/Applications`.
3. Сборка **не подписана** Apple Developer ID. При первом запуске Gatekeeper
   заблокирует приложение — откройте через **правый клик → «Открыть»** и
   подтвердите, либо снимите карантин:
   `xattr -dr com.apple.quarantine /Applications/BlockDuel.app`.

Universal binary (Intel x86_64 + Apple Silicon arm64), macOS 10.14+.

## Известные ограничения

- **Гостевой режим работает полностью офлайн** — играть можно сразу, без
  входа.
- **Онлайн PvP** требует доступного прод-сервера `pvp.alshfu.com` (WSS).
- **Google-вход на macOS** пока недоступен (требуется регистрация macOS-app в
  Firebase Console — см. `MACOS_AUTH_SETUP.md`). Без входа приложение работает
  как гость, кросс-девайс-синк недоступен. Появится в патче.
