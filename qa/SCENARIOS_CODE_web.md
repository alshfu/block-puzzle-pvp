# BlockDuel — Каталог сценариев платформы «Web (Flutter Web, прод)»

**Ровно 1001 сценариев** платформы «Web (Flutter Web, прод)» («1000 и 1»).
Ввод: мышь, тачскрин, клавиатура, трекпад. Хранение: SharedPreferences→localStorage. Деплой: gh-pages (GitHub Actions).
Сгенерировано детерминированно из `tools/gen_scenarios.py` (ось «код+платформа»).

- **ID** `CODE-WEB-0001…CODE-WEB-1001` стабильны между прогонами.
- **[C]** — критический smoke-срез (каждый ~7-й).
- Раздел «Код мода» — инварианты чистого ядра, одинаковые на всех платформах;
  хвост «Property-фаззинг» (прогон × конфиг × инвариант) добирает до 1001.
