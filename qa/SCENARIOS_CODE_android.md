# BlockDuel — Каталог сценариев платформы «Android»

**Ровно 1001 сценариев** платформы «Android» («1000 и 1»).
Ввод: тачскрин, жесты, аппаратная Back. Хранение: SharedPreferences→XML. Деплой: APK/AAB (Play).
Сгенерировано детерминированно из `tools/gen_scenarios.py` (ось «код+платформа»).

- **ID** `CODE-ANDROID-0001…CODE-ANDROID-1001` стабильны между прогонами.
- **[C]** — критический smoke-срез (каждый ~7-й).
- Раздел «Код мода» — инварианты чистого ядра, одинаковые на всех платформах;
  хвост «Property-фаззинг» (прогон × конфиг × инвариант) добирает до 1001.
