# BlockDuel — Каталог сценариев платформы «macOS (desktop)»

**Ровно 1001 сценариев** платформы «macOS (desktop)» («1000 и 1»).
Ввод: мышь, трекпад, клавиатура. Хранение: SharedPreferences→NSUserDefaults. Деплой: release .app/.dmg.
Сгенерировано детерминированно из `tools/gen_scenarios.py` (ось «код+платформа»).

- **ID** `CODE-MACOS-0001…CODE-MACOS-1001` стабильны между прогонами.
- **[C]** — критический smoke-срез (каждый ~7-й).
- Раздел «Код мода» — инварианты чистого ядра, одинаковые на всех платформах;
  хвост «Property-фаззинг» (прогон × конфиг × инвариант) добирает до 1001.
