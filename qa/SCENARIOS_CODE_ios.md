# BlockDuel — Каталог сценариев платформы «iOS/iPadOS»

**Ровно 1001 сценариев** платформы «iOS/iPadOS» («1000 и 1»).
Ввод: тачскрин, жесты, внешняя клавиатура (iPad). Хранение: SharedPreferences→NSUserDefaults. Деплой: App Store (TestFlight).
Сгенерировано детерминированно из `tools/gen_scenarios.py` (ось «код+платформа»).

- **ID** `CODE-IOS-0001…CODE-IOS-1001` стабильны между прогонами.
- **[C]** — критический smoke-срез (каждый ~7-й).
- Раздел «Код мода» — инварианты чистого ядра, одинаковые на всех платформах;
  хвост «Property-фаззинг» (прогон × конфиг × инвариант) добирает до 1001.
